# Project status

- State: Georg Kloster Bible Reader 1.1.11 release is prepared; WordPress.org publication starts when its annotated Git tag is pushed.
- Implemented: Dictionary words appear as cards and open in a popup while preserving the list. Dictionary article responses are kept in a bounded browser cache for 15 minutes. Alphabet selection is shown only when actual entry headings match a known alphabet; otherwise the reader starts with cards and search. On first dictionary open, the first available letter or first page of cards loads automatically. Only the AZBYKA_CU_FULL lexicon uses Bible Desktop's Church Slavonic alphabet/search endpoints. Church Slavonic headwords and articles use Monomakh. Dictionary cards and popup article text follow the reader font-size setting. Scroll loading fills the visible results area before waiting for further scrolling. Verses with personal notes show a note icon and count; expanding it reveals note text inline. Commentary reloads for the selected verse and displays only commentary entries whose range is exactly that verse, excluding book and chapter introductions. Parallel places reload for the selected verse, retain a visible spinner through text resolution, and show empty and error states. Reading history is available in the current session; the checkbox controls whether it persists in this browser. The dictionaries action is omitted from the verse context menu. Bible references still open the full chapter with the referenced verses highlighted; commentary stays in the resizable right pane. Release notes are present in English WordPress readme and in Russian, German, Ukrainian, and Polish README summaries.
